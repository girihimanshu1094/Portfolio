# Himanshu Giri Portfolio

A clean, dark-themed personal portfolio website for an MCA fresher or entry-level software developer. It is built with simple React components, Tailwind CSS, JavaScript and React Icons.

## Features

- Responsive sticky navbar with mobile hamburger menu
- Developer-style hero section with code editor card
- About section with editable quick facts
- Skills section grouped by category
- Reusable project cards
- Education cards with placeholders
- Achievements and certifications placeholder section
- Resume call-to-action using `/resume.pdf`
- Contact section with frontend validation
- Dark developer-focused UI

## Technologies

- React
- Vite
- Tailwind CSS
- JavaScript
- React Icons
